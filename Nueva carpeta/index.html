Esta sesión no es para cualquiera.

La Sesión de Claridad Financiera existe para evaluar si tu situación, tu nivel de conciencia y tu disposición al cambio están alineados con el Sistema Paz Financiera.

Esta sesión es para ti si...

  • Ganas $3,000 o más al mes.
  • Reconoces que necesitas algo más profundo que “hacer un presupuesto”.
  • Estás dispuesto a asumir responsabilidad por tus decisiones financieras.
  • Quieres educarte para dejar de repetir patrones con el dinero.
  • Estás listo para dejarte guiar, seguir instrucciones y sostener un proceso serio.

Esta sesión no es para ti si...

  • Buscas una fórmula rápida para salir de deudas sin cambiar hábitos.
  • Quieres invertir antes de ordenar tu base financiera.
  • Buscas préstamos, consolidaciones, refinanciamientos o soluciones mágicas.
  • Solo quieres información gratuita, pero no estás dispuesto a tomar acción.
  • No estás abierto a ser guiado.
